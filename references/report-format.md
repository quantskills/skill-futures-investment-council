# Report Format

## Required sections

1. Market overview
2. Market regime
3. Technical and trend
4. Futures structure
5. Commodity fundamentals
6. Expert opinions
7. Consensus
8. Conflicts
9. Invalidation conditions
10. Risk warning
11. Confidence and data quality

## Output rules

- Use `unknown` when data is missing.
- Do not output only `buy`, `sell`, `long`, or `short`.
- Explain disagreement when experts do not align.
